        What actually makes a password strong

        Five rules that matter more than anything else.

        • Length beats complexity. A 16-character password is dramatically harder to crack than an 8-character one, even with fewer symbol types.
        • Never reuse a password. If one site leaks it, every account using it is exposed too.
        • Random words work as well as random characters. Four to six unrelated words strung together is long, memorable and just as strong.
        • Save it somewhere real. A password manager remembers your passwords so you never have to reuse or simplify one again.
        • Turn on two-factor authentication. Even a perfect password can be phished — 2FA stops the attacker who already has it.

        Frequently asked questions

        Short answers to the things people ask most.

        Are online password generators safe?
        Only if they run entirely in your browser. This one does — the password is created with crypto.getRandomValues inside your device and is never transmitted. You can verify this by opening your browser's Network tab and generating a password: no request is sent. If a generator asks you to click "generate on server", close the tab.
        How long should my password be?
        For most accounts, 16 characters or more is a good target. For high-value accounts (email, banking, password manager) aim for 20+. Length adds entropy exponentially: every extra character multiplies the search space by the size of the character pool.
        What is a passphrase and why use one?
        A passphrase is several random words joined together (for example copper-lantern-otter-glide). Because words are easy to type and remember, you can make a passphrase much longer than a typical password without it becoming painful — and length is what actually stops attackers.
        What does "bits of entropy" mean?
        Entropy measures how unpredictable a password is. Each additional bit doubles the number of guesses an attacker would need on average. Roughly: <35 bits is weak, 35–59 is fair, 60–79 is strong, and 80+ is very strong against offline attacks.
        How does the leak check work without sending my password?
        It uses the k-Anonymity model from Have I Been Pwned. Your password is hashed with SHA-1 locally, and only the first five characters of that hash are sent to the API. The API returns every breached hash starting with those five characters — typically several hundred — and your browser checks whether your full hash is in that list. The server never sees your password or your full hash.
        Should I use a password manager?
        Yes. A manager lets you use a unique, long, random password for every site without memorising any of them. You only need to remember one strong master passphrase. This tool is for generating the passwords you then store in your manager.
